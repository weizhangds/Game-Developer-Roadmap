# Godot 独立游戏开发 · 学习路线图

一个可交互的学习路线图：**大目标（技能）拆成小目标（具体动作）**，每个小目标都能标「未学 / 学习中 / 已学」，大目标的状态由小目标自动汇总。

- 6 个阶段 · 98 个大目标 · 324 个小目标（接入进度统计的 318 项，另 6 项为可跳过内容）
- 每个大目标都写了**预计时间**和**验收标准**——达到标准再打勾，比凭感觉勾选可靠
- 顶部「接下来该做的 3 件事」自动指向排序上最靠前的未完成小目标

## 怎么用

- **单击小目标** → 未学 → 学习中 → 已学 循环切换
- **Shift + 单击** → 反向切换
- **单击大目标标题** → 折叠 / 展开
- **Shift + 单击大目标** → 整组小目标一起切到下一状态
- 顶部工具条：筛选（全部 / 只看必修 / 各状态 / 隐藏可跳过）、搜索、备份、恢复、重置
- 建议**每周日花 5 分钟**点一次，并「备份」导出一次 JSON

## 关于数据

进度保存在浏览器 `localStorage`（键名 `godot-roadmap-v2`），**不上传任何服务器**。换浏览器、清缓存、用无痕模式会丢失，请用「备份」导出 JSON。

## 自己部署一份

这是单文件静态网页，零依赖、零构建、可离线打开。

**GitHub Pages（免费）**

1. 登录 GitHub，新建仓库，勾选 Public
2. 把 `index.html` 上传到仓库根目录（网页端 "Add file → Upload files" 即可）
3. 仓库 Settings → Pages → Source 选 *Deploy from a branch* → 分支 `main` / 目录 `/ (root)` → Save
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

**其他托管**：Cloudflare Pages、Vercel、Netlify 都可以，直接拖这个文件夹进去即可，不需要任何配置。

**发给同学**：把 `index.html` 打包成 zip 发送，解压后双击打开即可（直接发 .html 容易被聊天软件拦）。

## 内容定位

面向「零基础起步、想走独立游戏开发、同时需要就业兜底」的软件工程本科生，路线以 **Godot 4 + GDScript 为主，C# 为辅**，前期用 C 打编程底子。顺序与时长是建议值，按自己的节奏调整。
